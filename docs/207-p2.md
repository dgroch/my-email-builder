# #207 P2 implementation and review notes

Implemented items 1, 2, 4, 8, 9 and 10 on `codex/207-p2`, based on `575e1a48a239950f76f384b9d46873b8053bb1c9`. No commits, pushes, branch changes, deployments or production API calls were made.

## Behaviour

- `products/card-feature`: live HTML, 280px 4:5 tile at desktop, card-live-style responsive columns with dedicated classes preserving the 280px tile at 600px, left/right image side, separate escaped plain alt, title/label/image destination, optional paragraphs/link row/button. Blank CTA omits both HTML button and Outlook VML. Required image, alt, destination, title and first paragraph validate.
- `sections/text-band`: type only; clay / 50clay / white / noir presets, optional headline/link row/second paragraph/final link, center/left alignment, 32px default vertical padding. Validation limits campaigns to two bands and checks paired final-link fields.
- `sections/body-copy-plain`: `ALIGN` center/left (default center), `MOBILE_ALIGN` inherit/left/center (default inherit), `TOP_RULE` on/off (default on), `PADDING_TOP`/`PADDING_BOTTOM` (44px), `PADDING_X` (64px), `MOBILE_PADDING_X` (24px). Blank lines in either body token create any number of table-cell paragraphs with the existing paragraph spacing and markdown styling. Manifest metadata exposes controls without changing legacy template documentation or default HTML. Mobile overrides use classes specific to their settings so adjacent blocks can differ.
- Trust-bar is removed from `ordering_rules.required`; the sibling `_note` states it returns when new artwork lands. A sendable campaign without it validates. Existing validator behaviour already allowed this; the failing-before test catches the manifest disagreement.
- `sections/full-width-image`: independent `PADDING_TOP`/`PADDING_BOTTOM`, default `0`. Selecting `24px` yields 24px at 600 and 16px below 600; other explicit lengths are preserved. Existing padding and wrapper bytes remain exact when off.
- `sections/top-line`: editable plain `TEXT`, fixed #EBE5DF / #000000, NeuzeitGro 12px/18px, .02em tracking, centred, 10px/24px padding, no link or rule. Live HTML and frozen publication plain text are tested. Plain-text tokens do not show the editor's markdown chip.
