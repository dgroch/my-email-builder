- `scripts/render-207-p1.js`: offline 600px screenshot capture and enabled-image pixel/geometry assertions. Uses one browser, closes pages/browser, intercepts all requests, aborts images for images-off, and serves a controlled local image fixture for images-on. It does not fetch original CDN artwork.
